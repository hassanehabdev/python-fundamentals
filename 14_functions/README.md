# Functions in Python

This folder contains reviewed Python exercises covering function definitions, arguments, return values, and variable scope across Lessons 24–27.

## Lessons Covered

### Lesson 24 – Functions Part 1
- Defining and calling functions
- Parameters and arguments
- Calling functions with loops
- Using loops and conditions inside functions
- Returning values from functions
- Getting user input and passing it to functions

### Lesson 25 – Functions Part 2
- Variable-length positional arguments using `*args`
- Iterating over function arguments
- Checking argument types
- Passing a tuple as a single argument
- Processing grades and calculating totals and averages
- Returning calculated values
- Passing lists to functions

### Lesson 26 – Functions Part 3
- Performing calculations with functions
- Returning Boolean values
- Calculating factorials
- Reversing strings
- Counting vowels
- Processing lists and calculating averages
- Summing squares
- Merging lists

### Lesson 27 – Global Variables
- Accessing global variables inside functions
- Understanding local and global variable scope
- Using the `global` keyword to modify global variables
- Updating global numbers, strings, lists, dictionaries, and sets
- Tracing code and identifying its output

## Files

- `functions_exercises.py` – Reviewed solutions for Lessons 24–27, organized by lesson and exercise.

## Purpose

These exercises provide practical experience with Python functions, argument handling, return values, loops, conditionals, collections, and variable scope.
