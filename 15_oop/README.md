# Object-Oriented Programming (OOP) in Python

## Overview

This section contains Python exercises covering the fundamentals of Object-Oriented Programming (OOP), including classes, objects, constructors, attributes, methods, importing classes from modules, inheritance, method overriding, and abstract classes.

The exercises are organized into five lessons and follow the order of the course material.

## Lessons Covered

### Lesson 28 – OOP (Introduction)

- Defining classes and creating objects
- Instance attributes and constructors (`__init__`)
- Instance methods
- Class variables and tracking object creation
- Default constructor parameters
- Accepting user input to create objects
- Using the `math` module to calculate circle areas

### Lesson 29 – Import

- Defining classes in separate Python modules
- Importing classes using `from module import ClassName`
- Creating objects from imported classes
- Organizing class definitions and main program code across Python files
- Using the `__del__` method

### Lesson 30 – Inheritance 1

- Parent classes and child classes
- Inheriting attributes and methods
- Using `super()` to initialize parent attributes
- Adding attributes and methods to subclasses
- Overriding inherited methods
- Practical examples involving shapes, vehicles, animals, products, and employees

### Lesson 31 – Inheritance 2

- Inheriting constructors and methods
- Method overriding
- Calling parent methods with `super()`
- Extending inherited behavior
- Using `NotImplementedError` to indicate methods intended for subclass implementation
- Practical examples involving employees, vehicles, shapes, characters, and garments

### Lesson 32 – Abstract Class

- Creating abstract base classes with `ABC`
- Declaring abstract methods with `@abstractmethod`
- Implementing abstract methods in subclasses
- Understanding why abstract classes cannot be instantiated before their abstract methods are implemented
- Applying abstraction to shapes, operations, authentication, vehicles, food, people, and payment processing

## Repository File

- `oop_exercises.py` – Reviewed Python solutions for Lessons 28–32.

## Learning Objectives

By completing these exercises, the learner practices structuring programs with classes and objects, reusing code through inheritance, customizing inherited behavior, and defining common interfaces through abstract classes.

The solutions are organized by lesson and include corrections and formatting improvements for readability and consistency.
