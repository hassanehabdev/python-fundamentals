
# For Loops in Python

This folder contains exercises covering iteration and repetition using `for` loops in Python.

## Lessons Covered

**Lesson 7 – For Loops**

Exercises: 1–10

### Topics Covered

- Iterating over sequences of numbers using `for` loops
- Using the `range()` function
- Understanding the start, stop, and step parameters of `range()`
- Printing numbers in ascending and descending order
- Using positive and negative step values
- Iterating through even and odd numbers
- Accumulating values using a loop
- Calculating the sum of numbers
- Calculating factorials using iteration
- Using augmented assignment operators (`+=`, `*=`)

## File Structure

- `for_loops_exercises.py` – Contains all 10 exercises and their Python solutions.

## Learning Focus

Understanding how `for` loops execute repetitive instructions, how the `range()` function controls iteration, and how loops can be used to process sequences of numbers and perform cumulative calculations.
