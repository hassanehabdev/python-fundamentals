# Operators in Python

This folder contains exercises covering variable reassignment and arithmetic operators in Python.

## Lessons Covered

### Lesson 4 – Variable Reassignment and Arithmetic Operators

**Exercises:** 1–10

Topics covered:
- Reassigning values to variables
- Updating variables using their current values
- Addition (`+`)
- Multiplication (`*`)
- Exponentiation (`**`)
- Division (`/`)
- Floor division (`//`)
- Modulus (`%`)
- Combining arithmetic operations

## File Structure

- `operators_exercises.py` – Contains the exercises and Python solutions.

## Learning Focus

Understanding how variables can be updated and how arithmetic operators perform calculations and modify stored values.
