# Variables in Python

This folder contains exercises covering Python variables, basic assignment, arithmetic operations, data types, and string handling.

## Lessons Covered

### Lesson 1 – Variables: Basic Assignment and Operations

**Exercises:** 1–10

Topics covered:
- Creating and assigning variables
- Printing variable values
- Performing arithmetic operations with variables
- Working with multiple variables
- Storing and displaying string values

### Lesson 2 – Variables: Data Types and Operations

**Exercises:** 1–10

Topics covered:
- Integer (`int`) data type
- Floating-point (`float`) data type
- Complex (`complex`) data type
- String (`str`) data type
- Boolean (`bool`) data type
- Checking variable types using `type()`
- Arithmetic operations between different data types
- Chained variable assignment
- Using single and double quotation marks in strings

## File Structure

- `variables_exercises.py` – Contains all 20 exercises and their Python solutions.

## Learning Focus

Understanding how variables store data, how Python handles different data types, and how variables can be used in expressions and operations.
