# Python `print()` — Output Exercises

## Overview

A collection of 10 beginner-level Python exercises focused on displaying text and patterns using the built-in `print()` function.

## Learning Objectives

- Displaying text using `print()`.
- Printing multiple lines.
- Using the newline escape sequence (`\n`).
- Understanding explicit line continuation (`\`).
- Creating simple patterns using strings and special characters.

## Exercises

1. Printing a basic text message.
2. Printing multiple lines using separate calls and `\n`.
3. Displaying multiline text.
4. Printing longer multiline messages.
5. Using explicit line continuation.
6. Printing multiple lines using alternative approaches.
7. Creating a simple rectangular pattern.
8. Extending a rectangular pattern.
9. Creating an increasing star pattern.
10. Creating an increasing and decreasing star pattern.

## File

- `print_exercises.py` — Contains the solutions to all ten exercises.

## Learning Focus

These exercises practise basic output operations, string handling, and control over how information is displayed in the console.
