# Operators in Python

This folder contains practical exercises covering variable reassignment and arithmetic operators.

## Lessons Covered

### Lesson 4 – Variable Reassignment and Arithmetic Operators

**Exercises:** 1–10

Topics covered:
- Reassigning values to variables
- Updating variables using their current values
- Addition (`+`)
- Multiplication (`*`)
- Exponentiation (`**`)
- Division (`/`)
- Floor division (`//`)
- Modulus (`%`)
- Combining arithmetic operations

## File Structure

- `operators_exercises.py` – Contains the exercises and their Python solutions.

## Learning Focus

Developing an understanding of variable reassignment and how arithmetic operators perform calculations and update stored values.
