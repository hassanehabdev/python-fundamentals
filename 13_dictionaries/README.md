# Dictionaries in Python

This section contains Python exercises covering dictionary creation, key-value pairs, data access, modification, removal, and iteration.

## Lesson 23 – Dictionaries

Topics covered:

- Creating empty dictionaries.
- Creating dictionaries using key-value pairs.
- Accessing values using dictionary keys.
- Updating existing values.
- Removing entries using `pop()`.
- Checking key existence using the `in` operator.
- Iterating through dictionaries using `for` loops.
- Accessing keys and values using `items()`.
- Adding new key-value pairs.
- Checking dictionary keys using user input.
