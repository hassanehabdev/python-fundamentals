# Lists and Tuples in Python

This section contains Python exercises covering lists and tuples, progressing from fundamental operations to more practical manipulation and processing.

## Lessons Covered

### Lesson 10 – Lists Part 1
- Creating and initializing lists
- Accessing list elements using indexing
- Adding elements using `append()`
- Iterating through lists using `for` and `while` loops
- Collecting user input into lists

### Lesson 11 – Lists Part 2
- Accessing and modifying list elements
- List repetition
- Iterating through lists
- Using `range()` and `len()`
- Finding elements using `index()`
- Classifying numbers as even or odd

### Lesson 12 – Lists Part 3
- Iterating through lists and calculating totals
- Processing selected list elements
- Copying lists
- List slicing and reverse slicing
- Concatenating lists
- Sorting lists

### Lesson 13 – Lists Part 4
- Membership testing using `in` and `not in`
- Adding elements using `append()` and `insert()`
- Removing elements using `pop()`
- Finding element occurrences using `index()`
- Sorting in ascending and descending order
- Reversing lists using `reverse()`

### Lesson 14 – Tuples
- Creating tuples
- Tuple unpacking
- Tuple concatenation and repetition
- Tuple slicing
- Membership testing
- Finding tuple length
- Converting lists into tuples
- Tuple iteration and indexing
