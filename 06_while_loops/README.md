
# While Loops in Python

This folder contains exercises covering repetition and iteration using `while` loops in Python.

## Lessons Covered

**Lesson 8 – While Loops**

Exercises: 1–10

### Topics Covered

- Using `while` loops to repeat instructions
- Defining and evaluating loop conditions
- Updating variables during loop execution
- Incrementing and decrementing counters
- Printing ascending and descending number sequences
- Iterating through even and odd numbers
- Using the modulus operator (`%`) to check divisibility
- Accumulating values using loops
- Calculating sums of numeric sequences
- Calculating factorials using iteration
- Controlling iteration through counter updates

## File Structure

- `while_loops_exercises.py` – Contains all 10 exercises and their Python solutions.

## Learning Focus

Understanding how `while` loops control repetitive execution through conditions, how counters and variable updates determine when loops terminate, and how loops can be used to process numbers and perform cumulative calculations.
