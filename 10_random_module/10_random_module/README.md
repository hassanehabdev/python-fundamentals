# Random Module in Python

This section contains Python exercises introducing the `random` module, alongside mathematical operations using Python's built-in `math` module.

## Lesson 16 – Import Random / Random Module

Topics covered:

### Math Module
- Calculating exponential values using `math.exp()`
- Calculating logarithms using `math.log()`
- Working with natural logarithms and Euler's number (`math.e`)
- Calculating cosine, sine, and tangent using `math.cos()`, `math.sin()`, and `math.tan()`
- Converting degrees to radians using `math.radians()`

### Random Module
- Generating random integers using `random.randint()`
- Generating random floating-point numbers using `random.random()`
- Selecting random elements from a list using `random.choice()`
- Shuffling list elements using `random.shuffle()`
