# Math Module in Python

This section contains Python exercises covering numeric conversions, mathematical operations, and the use of Python's built-in `math` module.

## Lesson 15 – Import Math / Math Module

Topics covered:

- Converting integers to floating-point numbers using `float()`
- Creating complex numbers using `complex()`
- Calculating absolute values using `abs()`
- Classifying numbers as negative, positive, or zero
- Finding maximum and minimum values using `max()` and `min()`
- Dividing numbers and rounding results using `round()`
- Importing and accessing the `math` module
- Accessing the mathematical constant `math.pi`
- Rounding numbers upward using `math.ceil()`
- Rounding numbers downward using `math.floor()`

## Purpose

Practice Python's built-in mathematical functions and understand how to import and use the `math` module to perform common mathematical operations.
