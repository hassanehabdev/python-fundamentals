# Working with Strings in Python

This section contains Python exercises covering string manipulation, string methods, character operations, searching, formatting, and validation.

## Lessons Covered

### Lesson 17 – Strings Part 1
- String concatenation and repetition
- Character indexing and negative indexing
- String slicing and length using `len()`
- String formatting using `%s` and `%d`
- User input and string operations
- Escape characters and backslashes
- Substring membership testing using `in`

### Lesson 18 – Strings Part 2
- Counting occurrences using `count()`
- Finding character and substring positions using `index()`
- Finding subsequent occurrences using a starting index
- String membership testing
- Searching using `find()` and `rfind()`
- Searching within specified index ranges
- Splitting strings using `split()`
- Splitting multiline strings using `splitlines()`

### Lesson 19 – Translate
- Replacing substrings using `replace()`
- Creating translation tables using `str.maketrans()`
- Translating characters using `translate()`
- Mapping multiple characters to different replacements
- Replacing characters with strings
- Removing characters using translation tables
- Converting uppercase letters to lowercase

### Lesson 20 – Strip and String Methods
- Converting strings using `upper()` and `lower()`
- Titlecase conversion using `title()`
- Capitalizing strings using `capitalize()`
- Joining characters using `join()`
- Centering strings using `center()`
- Padding strings with specified fill characters
- Expanding tabs using `expandtabs()`
- Removing leading and trailing characters using `strip()`

### Lesson 21 – Startswith and String Testing Methods
- Checking prefixes using `startswith()`
- Searching from a specified index
- Checking multiple prefixes using tuples
- Case-insensitive prefix and suffix checking
- Checking suffixes using `endswith()`
- Validating alphabetic strings using `isalpha()`
- Validating numeric strings using `isnumeric()`
- Validating alphanumeric strings using `isalnum()`
- Checking uppercase strings using `isupper()`

## Repository File

- `strings_exercises.py` – Contains the reviewed Python exercise solutions from Lessons 17–21.

## Purpose

Develop practical Python string manipulation skills, understand commonly used string methods, and strengthen problem-solving abilities through hands-on exercises.
