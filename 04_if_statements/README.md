
# If Statements in Python

This folder contains exercises covering conditional statements and decision-making in Python.

## Lessons Covered

**Lesson 6 – Conditional Statements (If, Elif, and Else)**

Exercises: 1–10

### Topics Covered

- Conditional statements using `if`
- Alternative conditions using `elif`
- Default execution using `else`
- Comparison operators (`>`, `<`, `==`, `<=`, `>=`)
- Logical operators (`and`, `or`)
- Chained comparisons
- Inclusive and exclusive numeric ranges
- Checking whether a number is even or odd using the modulus operator (`%`)
- Evaluating multiple conditions

## File Structure

- `if_statements_exercises.py` – Contains all 10 exercises and their Python solutions.

## Learning Focus

Understanding how conditional statements control program execution, how comparisons evaluate conditions, and how logical operators combine multiple conditions to make decisions.
