# Input in Python

This folder contains exercises exploring user input and how input values can be stored, converted, displayed, and processed in Python.

## Lessons Covered

**Lesson 9 – Input**

Exercises: 1–10

### Topics Covered

- Using the `input()` function to receive user input
- Displaying prompts to users
- Storing input in variables
- Understanding that `input()` returns a string
- Converting input using `int()` and `float()`
- Performing calculations using user-provided values
- Combining input with conditional statements
- Combining input with `for` loops
- Iterating through strings character by character
- Displaying messages and results

## File Structure

- `input_exercises.py` – Contains all 10 exercises and their Python solutions.

## Learning Focus

Understanding how Python programs receive information from users, store and convert input values, and use those values in calculations, conditional statements, and loops.
