# Sets in Python

This section contains Python exercises covering set creation, element management, set operations, and membership relationships.

## Lesson 22 – Sets

Topics covered:

- Creating sets using curly braces `{}`.
- Understanding unique elements and duplicate handling.
- Creating and working with multiple sets.
- Adding elements using `add()`.
- Performing union operations using `union()`.
- Performing intersection operations using `intersection()`.
- Checking subset relationships using `issubset()`.
- Removing elements using `remove()`.
- Clearing sets using `clear()`.
- Checking whether sets are empty using conditional statements.
- Understanding Boolean evaluation of empty and non-empty sets.
